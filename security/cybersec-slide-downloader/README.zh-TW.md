# CYBERSEC 2026 簡報下載器

一個基於 Node.js 的腳本，用於動態爬取並批次下載 CYBERSEC 2026 臺灣資安大會的所有簡報與附加檔案。

## 功能特點

- **GraphQL 整合**：直接向大會後端 API (`https://ccmsapi.ithome.com.tw`) 查詢完整的議程資料。
- **檔名自動淨化**：移除 Windows 檔案系統不支援的特殊字元，自動生成合法且清晰的檔名。
- **併發控制**：限制同時下載數量為 5 個，在保證下載效率的同時，避免因請求過於頻繁而被伺服器阻擋。
- **自動重試**：當遇到網路逾時或暫時性 HTTP 錯誤時自動重試下載。
- **下載報告**：下載完成後自動生成 `download_report.json` 摘要檔，記錄成功與失敗的下載清單。

## 環境需求

- [Node.js](https://nodejs.org/) (建議 v16.0.0 以上版本)

## 使用方法

1. 在此目錄下開啟終端機。
2. 執行下載腳本：
   ```bash
   node download_slides.js
   ```
3. 下載完成後的簡報將存放在 `downloads/` 資料夾內。
