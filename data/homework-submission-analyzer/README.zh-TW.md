# 🎓 電子商務安全管理 - 個人表現項目統計工具

本工具專為加速統計與審查學生的 Cisco 證書與實作作業所設計。它能自動掃描 `eeclass` 下載的作業包、提取 PDF 證書內文核對學員姓名，並對 PicoCTF、CDX 實作是「詳細文件」或「僅結果圖」進行自動辨識分類。

---

## 📂 檔案結構

請確保以下檔案置於同一個資料夾下：
* `run_report.js`：核心自動化統計腳本。
* `index.html`：`eeclass` 下載時自動產生的學生成績索引網頁。
* `[學生學號 (姓名)]/`：各學生的作業繳交子資料夾（包含 `content.html` 與上傳的實體附件）。
* `README.md`：本說明文件。

---

## 🛠️ 前置需求與執行步驟

本機已安裝 **Node.js**，腳本在首次執行時會自動偵測並下載相關的 PDF 解析套件 (`pdf-parse`)，您不需要手動配置。

### 執行步驟：
1. **解壓新作業包**：在 6/20 截止後，將從 eeclass 下載下來的所有同學作業資料夾解壓並覆蓋至本資料夾。
2. **開啟終端機**：在 `hw_68801` 資料夾路徑下開啟命令提示字元 (CMD) 或 PowerShell。
3. **執行統計指令**：
   ```bash
   node run_report.js
   ```
4. **取得報表**：執行完成後（約 3 ~ 5 秒），同目錄下會更新 **`submission_report.csv`** 統計表。

## 📊 CSV 統計欄位說明

輸出的 CSV 報告共有 6 個欄位，已預先加入 BOM 檔頭，可直接使用 **Excel** 雙擊開啟（無亂碼）：

| 欄位名稱 | 標記規格 | 說明 |
| :--- | :--- | :--- |
| **學號** | `114453001` 等 | 名冊中 42 名學生的學號。 |
| **姓名** | `黃奕鈞` 等 | 名冊中 42 名學生的姓名。若無繳交資料夾，後續欄位均為空白（代表**未繳交**）。 |
| **選項1 (Intro)** | `v` 或 異常說明 | **Introduction to Cybersecurity 證書**<br>若內文查驗正確顯示 `v`；若上傳錯誤證書會寫出實際課名。 |
| **選項2 (Essential)** | `v`、`v (Junior...)` | **Cybersecurity Essentials 證書**<br>若為 Essentials 單科證書顯示 `v`；若為新平台自動產生的三合一 `Junior Cybersecurity Analyst Career Path` 證書，會標記為 `v (Junior Cybersecurity Analyst Career Path)`，兩者皆屬合格。 |
| **選項3 (PicoCTF/CDX)** | `v (內容 - 類型)` | **PicoCTF 或 CDX 實作**<br>會自動截取其檔名的簡要內容並加上**檔案類型判定**：<br>• `.docx/.pdf` ➔ 標記為 `v (實作標題 - 詳細文件)`<br>• `.jpg/.png` ➔ 標記為 `v (實作標題 - 僅結果圖)` |
| **選項4 (其他加分)** | `v (內容 - 類型)` | **其他與課程相關加分成果**<br>標記方式同選項 3。若繳交多個加分檔案，會以 `\|` 連接。 |

## 🔍 自動化查驗規則 (底層邏輯)

* **證書所有人比對**：腳本會自動將 PDF 中的 Certificate Awardee 與學生的中文名字及英文拼音（包含常見的英譯拼音對照）進行模糊匹配。如果完全對不起來，會在「選項」欄位顯示對應的警示（但為避免干擾登記，已移除了獨立的警示欄位）。
* **選項一二寫反判定**：若學生將 `選項1` 命名為 `Essential` 但 PDF 實體是 `Intro`（或反之），腳本會自動抓取 PDF 實際內容並於該選項填入 `v`。
