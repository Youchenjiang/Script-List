# 如何免費下載並安裝 HEVC 視訊擴充功能

HEVC (高效視訊編碼) 是播放高品質、小檔案視訊的標準。如果您的 Windows 無法直接播放 HEVC 檔案，可按照以下步驟免費安裝。

## 步驟 1：取得 Microsoft Store 應用程式 URL
複製下列來自設備製造商的 HEVC 擴展商店連結：
`https://www.microsoft.com/en-us/p/hevc-video-extensions-from-device-manufacturer/9n4wgh0z6vhq`

## 步驟 2：產生直接下載連結
1. 造訪 [Adguard Store 頁面](https://store.rg-adguard.net/)。
2. 在輸入框中貼上步驟 1 的連結。
3. 點擊旁邊的勾選按鈕產生連結。

## 步驟 3：下載與安裝
1. 尋找清單中的 `.appxbundle` 檔案（通常約 8MB，請確認架構如 x64 符合您的系統）。
2. 點擊連結下載。如果瀏覽器阻止，請手動選擇「保留」。
3. 雙擊下載的檔案進行安裝。

---
> [!NOTE]
> 此方法是透過第三方工具從微軟官方伺服器抓取原始安裝包，安全可靠且無需額外付費 (2026年4月實測有效)。
