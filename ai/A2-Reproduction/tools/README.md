# Tools Directory

This directory contains external tools and local dependencies required for the A2 system.

## Contents

- **jadx/**: Local installation of the JADX decompiler (v1.5.0). This is automatically installed by the `setup_jadx.py` script to avoid system PATH dependency issues.
- **scripts/**: (Optional) Helper scripts for environment setup or maintenance.

> **Note**: Most tools in this directory are git-ignored as they are binary dependencies or locally generated.
