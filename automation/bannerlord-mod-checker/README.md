# Bannerlord Mod Localization Checker

A PowerShell utility for Mount & Blade II: Bannerlord players and modders to inspect the localization file status across all installed game modules.

[繁體中文版](README.zh-TW.md)

---

## Usage

```powershell
# Run with default Steam directory
.\check_mods.ps1

# Specify custom game modules directory
.\check_mods.ps1 -BasePath "E:\Games\Mount & Blade II Bannerlord\Modules"
```
