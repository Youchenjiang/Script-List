# 騎馬與砍殺 2 模組語系檢查工具 (Bannerlord Mod Checker)

用於《騎馬與砍殺 II：領主》（Mount & Blade II: Bannerlord）的 PowerShell 檢查工具，可自動遍歷 Modules 目錄，檢測各 Mod 是否已具備中文（zho-CN/zho-TW）本地化語言檔案。

[English Version](README.md)

---

## 使用方式

```powershell
# 使用預設 Steam 遊戲路徑執行
.\check_mods.ps1

# 指定自訂遊戲模組路徑
.\check_mods.ps1 -BasePath "E:\Games\Mount & Blade II Bannerlord\Modules"
```
