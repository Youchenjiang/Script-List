# 活動公告收錄範圍

此政策取代初期研究文件中「BambooFox 整份日曆均可發布」的判斷。日曆可以公開讀取，不代表其中的活動向外界開放。

- 收錄公開資安社群聚會、講座、工作坊、研討會與競賽。
- 排除例行社課、迎新、社團博覽會、助教時間、內部培訓與限制校內／社員參與的項目。
- SCIST、BambooFox 日曆項目需要標題或描述明確提供對外開放資訊及資安內容；缺少證據時不發布。
- 其他來源同樣套用例行社團活動與內部參與限制的排除規則。

篩選採文字規則，可能漏掉未寫明資格的公開活動；不能僅因抓得到資料就視為可參加。初期實測 BambooFox 的 7 個日曆項目不再等於 7 個可公告活動。

公告日期仍由設定的時區換算，預設 Asia/Taipei；畫面省略重複的時區註記。「不限人數」必須有來源依據，缺少人數資料不得當成不限。

本次只修正收錄條件與用字。固定活動看板、每週彙整及成員訂閱提醒仍是待實作方案。
